**GENERAL MVP — PRODUCT PAGE STRUCTURE** 

**1. PAGE STRUCTURE**

There are only **two main sections**:

- Fresh Produce
- Cooking Kits

**2. FRESH PRODUCE SECTION**

**Default View:**

When no filter is selected:

- Display a **limited portion of items (not all)**
- Include a **“Show All” option** to expand and view the full list

**Filter System:**

Users can filter items by:

- Vegetables
- Tubers
- Herbs & Spices
- Legumes

When a filter is selected → show only items in that category

“Show All” resets the view

**Search:**

- Include a **search bar at the top of Fresh Produce**
- Users can search for specific items instead of scrolling or filtering

**3. COOKING KITS SECTION**

- Displayed as a separate section below Fresh Produce

**Layout:**

- Can be either:
    - Horizontal scroll (swipe), OR
    - Grid layout

Final choice should be based on what looks best visually.

**4. PRODUCT INTERACTION**

Clicking on any product:

Should **NOT open a new page**

Should open a **floating panel (overlay/modal)** on the same screen

**5. PRODUCT PANEL (FRESH PRODUCE)**

**Display:**

Product images (carousel, multiple images allowed)

Prep options

Quantity selector (+ / −)

Price (use placeholder “00” for now)

**Notes:**

No size options

No customer notes section

**6. PRODUCT PANEL (COOKING KITS)**

**Display:**

Product images (carousel)

Kit Contains (clearly listed)

Prep Style OR Type

Size options:

- Serves 1
- Serves 3
- Serves 5

Quantity selector (+ / −)

**Customer Notes section**

Price (placeholder “00”)

**7. CUSTOMER NOTES (KITS ONLY)**

Include a text input field for kits only.

**Placeholder:**

“Tell us any preferences (e.g. no garlic, don’t blend onions, less pepper, etc.)”

**8. IMAGE HANDLING**

Multiple images per product

Swipeable carousel

Can include prep-style visuals

**9. PRICING**

Every product should display a price

Use **“00” as placeholder** for now

**Placement:**

Price should be visible on product cards

Price should also be shown inside the product panel

Final price updates based on:

- Quantity
- (For kits) selected size

**10. QUANTITY SYSTEM**

All items use + / − selector

For kits:

Size is selected first

Quantity = number of packs

Example:

Serves 1 × Quantity 2 → 2 separate packs

**11. NO MULTIPLE PAGES**

Entire experience stays on one page

Uses sections + filters + floating panels

**12. DISCLAIMER**

All disclaimers (e.g. allergies, liability) should be placed at **checkout**, not here

#### **NB (FOR DESIGN + UX CLARITY)**

Each kit should have:

**Size Options (Portions):**

Serves 1

Serves 3

Serves 5

**Quantity Selector:**

A plus (+) and minus (−) control to increase or decrease the number of packs.

This means a user can select a size (e.g. Serves 1) and then choose multiple quantities (e.g. 2 packs of Serves 1).

The size selection should be a single choice (only one can be selected at a time), while quantity can be increased freely.

**Customer Notes Section:**

There should be a text input field where customers can specify preferences or exclusions for their order.

This allows users to customize their kits based on personal taste or dietary needs.

**Placeholder text example:**

“Tell us any preferences (e.g. no garlic, don’t blend onions, less pepper, etc.)”
