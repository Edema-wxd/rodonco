## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Next.js server → DB (Neon via Drizzle) | Reads from DB; must not leak secrets; must avoid injection. |
| Browser → Next.js server rendering | Uses DB results to render UI; must ensure safe string handling for user-provided DB fields. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|----------|----------|-----------|-------------|-----------------|
| T-02-03 | T (Tampering) | `getActiveProducts...` reads | mitigate | Use Drizzle query builder + typed schema (no string-concatenated SQL); filter on `is_active=true` only. |
| T-02-04 | I (Information Disclosure) | `/shop` SSR | accept | Only renders product + ordering config fields; no secrets. |
| T-02-05 | D (DoS) | Starting price helper | mitigate | Avoid N+1 queries; use one/two bounded queries and limit selected columns. |
| T-02-06 | XSS | Product name/description rendering | mitigate | Render as plain text; do not use `dangerouslySetInnerHTML`. |
</threat_model>
