## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Card internal element gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, grid gap |
| xl | 32px | Layout gaps, hero vertical padding |
| 2xl | 48px | Major section breaks (hero → How It Works) |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Navbar height: 64px (`h-16`) — established in Phase 1, do not change
- Cutoff banner stacks below Navbar: `sticky top-16 z-40` (compensates for the 64px Navbar)
- Cart icon touch target: 44px minimum (WCAG 2.5.5) — apply `min-h-[44px] min-w-[44px]` on the cart `<Link>` in Navbar if not already met
- Hero vertical padding: 96px (`py-24`) — Hero vertical breathing room — exceeds 64px max to provide visual separation on large viewports.

## Layout Contracts

### Page: `/` (Landing)

Primary focal point: hero headline + green CTA button.

Structure (top → bottom):
1. `<Navbar />` — sticky top-0 z-50, height 64px
2. Hero section — full-width, white background, center-aligned
   - Headline: Display role (36px bold)
   - Subheadline: Body role (16px regular), `text-muted-foreground`
   - CTA button: green `#16a34a`, links to `/shop`, size `lg` (36px height from button variants)
   - Vertical padding: `py-24` (96px top/bottom — declared exception; hero vertical breathing room)
3. How It Works section — `bg-secondary` (near-white), `py-16` (64px)
   - Section heading: Heading role (20px bold), centered
   - 3-column grid on md+, stacked on mobile
   - Each step: Lucide icon + label (Heading role, 20px bold) + description (Body role, 16px)
   - Step icons: `Search`, `Settings2`, `Truck` (placeholders — swap when brand assets arrive)
   - Step labels: "Browse", "Customise", "Deliver"

### Page: `/shop`

Structure (top → bottom):
1. `<Navbar />` — inherited from layout
2. `<CutoffBanner />` — `sticky top-16 z-40`; amber; null when ordering open
3. Page content — `max-w-7xl mx-auto px-4 py-8`
4. "Fresh Produce" section — heading + divider + product grid
5. "Cooking Kits" section — heading + divider + product grid

Grid: `grid grid-cols-2 sm:grid-cols-2 lg:grid-cols-3 gap-6`

Source: CONTEXT.md D-12, D-13, D-14

### Product Card

Layout (top → bottom):
1. Image — `aspect-[4/3] w-full object-cover rounded-t-xl`
2. Content area — `p-4 flex flex-col gap-2`
   - Product name — Heading role (20px bold)
   - Price — Label role (14px regular): "From ₦X,XXX"
   - "Add to Order" Button — `variant="default"` (solid black), `w-full`, `<Link href="/shop/[id]">`

Card container: `rounded-xl shadow-sm hover:shadow-md transition-shadow overflow-hidden bg-card`

Source: CONTEXT.md D-07, D-08, D-09, D-10, D-11

## Null / Error States

| Scenario | Behaviour |
|----------|-----------|
| `image_url` is null on product | Render `<Image src="/images/placeholder-product.jpg" alt="{product name}" />` — create placeholder at this path |
| Section has no active products | Show section heading + divider + `<p className="text-muted-foreground text-sm">No products available</p>` |
| DB fetch error on shop page | Next.js will throw; let the error boundary handle it (no custom error UI in Phase 2) |
| `ordering_config` fetch returns null | Default to `is_ordering_open = true` (safe — shows banner only on explicit false) |

Source: CONTEXT.md D-15; REQUIREMENTS.md SHOP-03

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Cart icon label | `aria-label="Cart"` on the `<Link>` wrapper (already in Navbar) |
| Cart badge | Hidden from screen readers when count is 0 (controlled by `useHasHydrated && itemCount > 0`) |
| Product card image | `alt="{product name}"` |
| Cutoff banner | `role="alert"` on the banner element so screen readers announce it |
| How It Works icons | `aria-hidden="true"` on decorative Lucide icons |
| Button focus | shadcn base-nova handles `focus-visible:ring-3 focus-visible:ring-ring/50` |
| Colour contrast | Amber-800 on amber-50 passes WCAG AA (7.2:1); white on green-600 passes AA (4.7:1) |

## Data Fetching Notes (for planner/executor)
