# Phase 02.1: migrate-supabase-to-neon-and-uploadthing — Plan 02 Summary

**Admin-only authentication migrated to NextAuth v5 Credentials with an edge middleware guard for `/admin/*` and an idempotent admin seed script (bcrypt cost 12).**

## Accomplishments
- Implemented NextAuth v5 Credentials `authorize()` against the `admins` table with bcrypt verification.
- Added `/api/auth/[...nextauth]` route handler exporting `{ GET, POST } = handlers`.
- Implemented `/admin/*` middleware redirect: unauthenticated `/admin/orders` returns **307 → /admin**.
- Added `npm run seed:admin` script and `scripts/seed-admin.ts` to seed initial admin row idempotently.
