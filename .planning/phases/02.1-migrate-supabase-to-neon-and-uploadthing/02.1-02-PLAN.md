NextAuth v5 Credentials pattern (verified — RESEARCH.md Pattern 4):
```typescript
import NextAuth from "next-auth";
import Credentials from "next-auth/providers/credentials";
import { db } from "@/lib/db";
import { admins } from "../drizzle/schema";
import { eq } from "drizzle-orm";
import bcrypt from "bcryptjs";

export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    Credentials({
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" },
      },
      authorize: async (credentials) => {
        if (!credentials?.email || !credentials?.password) return null;
        const [admin] = await db
          .select()
          .from(admins)
          .where(eq(admins.email, credentials.email as string))
          .limit(1);
        if (!admin) return null;
        const valid = await bcrypt.compare(
          credentials.password as string,
          admin.password_hash
        );
        if (!valid) return null;
        return { id: admin.id, email: admin.email };
      },
    }),
  ],
  session: { strategy: "jwt" },
});
```

Middleware pattern (RESEARCH.md Pattern 6) — Next.js 15 uses `middleware.ts` (NOT `proxy.ts` which is Next.js 16+):
```typescript
import { auth } from "@/auth";

export default auth((req) => {
  if (!req.auth && req.nextUrl.pathname.startsWith("/admin")) {
    const loginUrl = new URL("/admin", req.nextUrl.origin);
    return Response.redirect(loginUrl);
  }
});

export const config = {
  matcher: ["/admin/:path*"],
};
```

CRITICAL: matcher uses `:path*` (asterisk), NOT `:path+` (plus).
- `:path*` matches `/admin/orders`, `/admin/products`, etc. but NOT `/admin` itself (the login page)
- `:path+` would match `/admin` itself — causes infinite redirect loop (RESEARCH.md Pitfall 4)

Seed script pattern (RESEARCH.md Pattern 9):
```typescript
import "dotenv/config";
import { drizzle } from "drizzle-orm/neon-http";
import { neon } from "@neondatabase/serverless";
import { admins } from "../drizzle/schema";
import bcrypt from "bcryptjs";

const sql = neon(process.env.DATABASE_URL!);
const db = drizzle({ client: sql });

async function seed() {
  const email = process.env.ADMIN_EMAIL;
  const password = process.env.ADMIN_PASSWORD;
  if (!email || !password) throw new Error("ADMIN_EMAIL and ADMIN_PASSWORD must be set");
  const password_hash = await bcrypt.hash(password, 12);
  await db.insert(admins).values({ email, password_hash }).onConflictDoNothing();
  console.log("Admin seeded:", email);
  process.exit(0);
}

seed();
```

<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ⇄ /api/auth/* | Untrusted credentials submitted; NextAuth verifies via authorize() |
| Browser ⇄ /admin/* | Edge middleware checks JWT cookie before allowing through |
| Seed script ⇄ admins table | ADMIN_PASSWORD enters memory only at seed time, hashed before storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-06 | Spoofing | Admin login (Credentials provider) | mitigate | bcryptjs cost 12 (T-01 standard); `authorize()` returns `null` on missing fields, missing user, or mismatched hash — no information leak between cases |
| T-02.1-07 | Tampering | Session JWT forgery | mitigate | NextAuth signs JWT with `AUTH_SECRET` (≥ 32 random bytes generated by `npx auth secret` per Pitfall 2); strategy `"jwt"` and per-restart secret rotation requires re-login of all admins (acceptable for single-admin MVP) |
| T-02.1-08 | Elevation of privilege | `/admin/*` accessible without session | mitigate | `middleware.ts` matches `/admin/:path*` and redirects unauthenticated requests to `/admin`; matcher uses `:path*` not `:path+` to avoid login-loop (Pitfall 4) |
| T-02.1-09 | Information Disclosure | `password_hash` returned to client | mitigate | `authorize()` returns only `{ id, email }`; `password_hash` never crosses the boundary; bcryptjs constant-time compare |
| T-02.1-10 | Tampering | Weak admin seed password | mitigate | `scripts/seed-admin.ts` reads `ADMIN_PASSWORD` from env (T-06 standard); README/.env.local.example documents minimum complexity (≥ 12 chars, mixed) — Plan 04 records the requirement |
| T-02.1-11 | Denial of Service | Credential brute-force | accept | NextAuth has no built-in rate limiting; acceptable per RESEARCH.md security domain (single admin, not exposed to public, app pre-launch). Future ASVS-L2 work would add rate limiting at edge — deferred to v2 |

</threat_model>
