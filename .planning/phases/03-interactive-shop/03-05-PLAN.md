  <action>
    - Create `ProductDrawer` as a client component that receives:
      - `product`, `variants`, `prepOptions`
      - `isOrderingOpen` + `cutoffMessage`/`nextDeliveryDate` (optional)
    - Motion + layout (SHOP-06):
      - Overlay backdrop and panel that behaves as bottom sheet on mobile and side panel on desktop.
      - Animate open with `duration: 0.3, ease: "easeOut"`.
      - Swipe-to-close on mobile using motion drag (`drag="y"`) with a clear close threshold.
    - Close controls (D-02/D-03):
      - Backdrop click closes.
      - X button closes.
      - Swipe closes.
      - Close action should call `router.back()` to preserve the `/shop` page state and scroll semantics.
    - Configuration rules (D-05/D-06/D-07, SHOP-07/08/09):
      - If product.type === "cooking_kit": show **size variant selector only**; do not show prep UI even if prepOptions exist (D-06 locked).
      - If product.type === "fresh_produce": show **prep option selector only**; do not show size UI.
      - If the relevant option list is non-empty, require explicit selection: initialize selection state to `null` and keep Add to cart disabled until chosen (D-07).
      - If there are no options for that product type, allow quantity-only adds (D-05).
    - Quantity + subtotal-only pricing (D-08/D-09, SHOP-10):
      - Quantity min 1.
      - Soft warning UI when quantity > 20 (no hard max).
      - Render **subtotal only** (no explicit unit price display).
      - Compute subtotal in integer kobo using a single deterministic rule:
        - **Cooking kits**: `unitPriceKobo = selectedVariant.price_ngn`
        - **Fresh produce**: `unitPriceKobo = produceBasePriceKobo + (selectedPrepOption?.extra_cost_ngn ?? 0)`
          - `produceBasePriceKobo` comes from **the cheapest variant price** for that product (`MIN(product_variants.price_ngn)`), but the variants are NOT rendered as a selector (produce is prep-only per D-06).
        - `subtotalKobo = unitPriceKobo * quantity`
    - Ordering closed enforcement (D-12/D-13, SHOP-11):
      - Render sticky `OrderingClosedBanner` when closed.
      - Disable Add to cart button and show a tooltip-style hint when closed.
    - Add to cart behavior (D-04/D-10/D-11):
      - On Add to cart: call `useCartStore.addItem` with `variantLabel` and `prepOption` set appropriately and `subtotalNgn` computed.
      - After adding: call `useCartUiStore.autoOpenOnFirstAdd()` and then close drawer with `router.back()` (D-04).
  </action>

    - When ordering is closed, CTA is disabled with tooltip and banner is visible.
    - Add-to-cart closes the drawer and triggers cart sidebar auto-open only on first add.
  </done>
